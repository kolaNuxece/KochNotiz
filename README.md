# KochNotiz

A recipe management Android application built with Kotlin.

## About

KochNotiz is a personal project designed to make it easy to save and manage cooking recipes in one place. The application allows users to add recipes and store their information locally for later access.

## Features

- Add new recipes
- Save recipe information in a local database
- Access saved recipes after restarting the application
- Keep recipes organized in one place

## Technologies

- Kotlin
- Android
- Local database
- Gradle

## Project Status

KochNotiz is a personal learning project that I continue to develop and improve. Additional features and improvements may be introduced over time.

## What I Am Learning

Through this project, I am gaining practical experience with Android development, database integration, data persistence, and application structure.
